# Mapping to 43030 Software Development topics

- **Lecture 1 — GitHub Essentials:** Repository, branch, commits, issue and pull request. Local clone/rebase/reset/revert experiments must be done separately if claiming them.
- **Lecture 2 — GitHub Workflow:** YAML-based CI with push and PR triggers, ordered jobs and logs. This lab intentionally does not make recursive write-backs from its CI job.
- **Lecture 3 — Custom GitHub Actions:** Local composite action validates events. Dockerfile builds and runs a Python tool. This differs from the lecture's vowel-frequency Docker action.
- **Lecture 4 — GitHub Projects:** Issue #1 and an associated PR model real task tracking. Creating an actual Projects board and running the lecture's TaskPool project remain separate tasks.
- **Cybersecurity:** Python rule-based analysis of synthetic authentication logs. Two alerts are expected: repeated failed logins and late administrator login.

For the learning report, link relevant workflow results and record which activities you personally completed and what you learned.
